# XF 实时首答评测脚本

这里保留 29 点和 51 点纯 LLM XF 对照实验的运行、回放和盲评验收脚本。原始牌谱、请求、答复、评分包和凭据保存在本地证据目录。Git 仅追踪实验脚本。

脚本按冻结批次目录布局解析路径。复查时从本地归档还原实验目录，保留脚本和各批次目录的相对位置，再以证据根作为 `common` 参数。计划绑定脚本的原始字节哈希，因此这里保留原脚本的换行。`xf-release-old29/extension` 提供实验所用的 v0.16.17 运行时。

`xf-current-facts-test.cjs` 驱动当前事实卡和旧弃牌比较表对照。`xf-verified-comparison-test.cjs` 驱动旧表和新版核对表的第二轮对照。两者的 `--check` 走模拟请求，`--audit` 核对真实请求、用量和账本。对应的 `*-review.cjs` 导出和验收盲评。付费运行需要当前批次独立的 `LIVE_APPROVAL.json`，历史授权记录只用于审计。
