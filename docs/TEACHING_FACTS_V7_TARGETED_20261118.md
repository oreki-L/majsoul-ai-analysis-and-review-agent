# Mortal 教学 v7 定向回归

本轮以 [11 月 17 日实测](TEACHING_FACTS_V6_LIVE_20261117.md)为基线。上一版提示词 v6、事实卡 v5 交付 127/127，盲评通过 111/127；25 个点留下 26 条错误记录。当前工作区升级为提示词 v7、事实卡 v6。新版 31 点全部交付并完成正式盲评：同点通过数从 15 增至 25，但仍有新增重大错误，未达到预设接受条件。

| 实测错法 | 本轮改动 |
| --- | --- |
| 候选串行、跨向听直接比进张、误判并列或唯一听牌 | 保留三列效率表；对所选牌给出同向听档中进张更大、相等的候选数和本档最高值，另列形状听牌候选数及确有唯一时的弃牌。表不完整时不出比较结论，已见范围不完整时不出同档上界排名。赤五按精确弃牌实体单列。 |
| 把客风说成自风，把指示牌当宝牌；同种牌已见完仍说能摸成对子 | 选定牌直给自风、场风、三元牌、赤五、指示牌宝牌及同种已见范围。程序未知的身份保留 `null`。已有含幺九或字牌的副露单独标记为排除断幺。 |
| 把牌河索引当巡目，遗漏特定对手的筋 | 为对应玩家给一基弃牌序号和筋参考，保留原零基索引。巡目仍只读当前局况，筋参考和已确认安全分别表述。 |

教学仍只解释已校验的 Mortal 动作。模型自行判断是否有必要比较备选；没有充分依据可以明确说明。JSON 的 `summary`、`reasons`、`limitations` 及一次格式修复的行为沿用原合同。

定向清单共 31 点：25 个实测错例节点全部纳入，另加 6 个原本无记错且盲评通过的保护点，覆盖首巡、后段门清、赤五、鸣牌后弃牌、立直威胁和南二局二本场。全部使用同一提示词、同一解释模型、同一规则。运行优先覆盖唯一听牌、多个听牌和跨向听比较；标签仅用于复核和统计。本清单按既知问题选样，不能把结果外推到原本 127 点的总体通过率。

逐点校验原始输入、缓存引擎动作与本次生产生成的当前快照消息。生产历史会话会随提示词版本变更，因此基准在进入 Pi 前放回上一轮实际发送的历史前缀；不会把旧答案当作新版答卷，也不会把先跑出的新版教学写入后续试题。当前事实、动作、工具、解析与格式修复均走新版生产代码。历史基线和错误标签只用于配对，盲评包不包含版本、历史得分或错例标签。

在工作区根目录可复现离线回放和正式入口校验：

```powershell
$source = 'research/evidence/current-teaching-v6-live-20261117'
$output = 'research/evidence/current-teaching-v7-targeted-cny10-20261118'
node benchmark/current-teaching-v7/regression.cjs $source $output 10
node benchmark/current-teaching-v7/live.cjs verify $source $output
```

`manifest.json` 固定代码、评分规则、历史与样本动作；`offline-report.json` 记录离线结果。定向回放 31/31 通过，共 52 次模拟模型响应，覆盖直接回答、工具续接和一次 JSON 修复。新引擎推理、真实 API 请求、API 费用及质量评分均为 0。`offline-review` 只用于校验盲评包结构，不能用于正式评分。

正式回归入口为 `live.cjs --dispatch SOURCE OUTPUT MAX_POINTS`。它使用原 `deepseek-flash` 配置，不发起新 Mortal 推理。每轮离线准备时指定新的输出目录和金额，生成独立账本；同一轮续跑沿用原账本和额度。每个 HTTP 请求（含工具续接和格式修复）须先预留 2.12992 元，按用量结算后再判断能否发送下一次。额度不足或用量不明时停止；已尝试样本保留，未启动样本单列。

本轮 31/31 交付，31 点均保留冻结的 Mortal 动作，未重新推理。共 32 次真实 API 请求（31 次初答、1 次格式修复成功），模型没有调用工具。端到端耗时中位数 3.89 秒、P95 4.95 秒。10 元预算按返回用量估算支出 1.12487344 元，剩余 8.87512656 元，无未结算请求。原始结果在输出目录的 `live/results.jsonl`，盲审材料在 `live/review/`，预算在 `budget/budget.json`。

正式答卷沿用 `gpt-6.1-sol`、`medium` 独立盲评。逐点检查旧错误是否复现，标记新增重大错误，并核查保护点是否从通过降级。定向接受条件为已测目标错误减少、无动作改写、无新增重大错误，且已测保护点保持通过。未交付不进入内容均分，在端到端指标按零计；未启动单列，不算成解释失败。若预算导致覆盖不足，报告实际覆盖和结论边界。
