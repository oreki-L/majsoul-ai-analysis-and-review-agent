# Mortal 教学 v11 定向回归准备

提示词 v11、事实卡 v10 针对 [v10 实测](TEACHING_FACTS_V10_TARGETED_20261120.md) 中新增的两条重大错误。Mortal 动作、解释 JSON 合同和备选比较规则保持不变。

- `actionTransition.shantenWording` 由程序使用当前冻结暗手和所选弃牌后的向听数生成。摘要和理由若描述向听变化，共用同一句结论；任一向听数未知时不描述变化。当前暗手已含摸牌或已完成鸣牌，不能把先前发生的变化归因于本次弃牌。
- `explanationFocus.discard.localLinks` 沿用各补牌的未见上界，并给相关局部搭子一条 `completionSupply` 结论。只有计数完整且所有补牌上界均为零，才说整组补牌已见尽。计数部分缺失或冲突时，整组结论为空；上界始终不是牌山实际剩余。
