# Mortal 教学 v9 定向回归

提示词 v9、事实卡 v8 针对 [v8 实测](TEACHING_FACTS_V8_TARGETED_20261119.md) 的两个新重大错误。v8 实测交付 40/40，盲评通过 38/40，内容均分 3.675/4；上一轮 6 个重大错例均已通过。这是历史参照，不是 v9 成绩。

- 所选弃牌后为形状听牌时，`explanationFocus.discard.tenpai.shapeWaits` 直接列每种听口与未见枚数上界。局部搭子的补牌不能追加为整手听口；上界为零的牌仍是形状听口，但没有未见枚数。原三列候选效率表不扩列。
- `knownYakuByDiscard` 将已验证的役种绑定到精确弃牌和补牌。四麻中检查指定补牌的完整和牌拆分，目前提供三色同顺和役牌的正面证据。没有条目只表示未确认，不等于无役。仍不判断振听、条件役、得点或候选合法性。一组役种可能来自不同拆分，不能累加为同一手的番数。
- Mortal 动作、JSON 输出合同和一次格式修复保持原样。用户未要求比较时，由模型自行决定是否比较。

下轮用原来的 40 点做 v8 → v9 同点对照。先测试「打 6 筒后错把 5 筒列为听口」和「忽略弃 5 万的三色同顺」两个节点，再复查 v8 已通过的 38 点。全部点用同一配置，保留原快照、缓存动作和历史输入；评分沿用 `gpt-6.1-sol`（medium）独立盲评。验收看两个重大错例是否消失、是否有新增重大错误，以及原通过点是否退步。未交付单列，不计入内容均分。

研究工作区可复现离线准备与入口校验：

```powershell
$source = 'research/evidence/current-teaching-v6-live-20261117'
$prior = 'research/evidence/current-teaching-v8-targeted-cny10-20261119'
$output = 'research/evidence/current-teaching-v9-targeted-cny10-20261119'
node benchmark/current-teaching-v9/regression.cjs prepare $source $prior $output 10
node benchmark/current-teaching-v9/regression.cjs verify $source $prior $output
```

40/40 点离线回放通过，包含直接回答、工具续接、格式修复，共 67 次模拟响应。两个失败点的程序事实已验证：选定弃牌后只列 3 筒和 4 筒；弃 5 万后补 2 万列出三色同顺，弃 1 万未列已确认役种。

## 11 月 20 日正式实测

正式运行前核对了 v0.16.14 标签与工作区的提示词、事实卡、本地麻将分析及 Worker 关键文件。40/40 点交付，保留全部冻结的 Mortal 动作，没有重新推理。沿用原解释模型配置，共 42 次真实请求（40 次初答、2 次格式修复成功），没有工具续接。端到端耗时中位数 3.08 秒，P95 4.20 秒。独立 10 元账本按用量估算支出 1.46677584 元、剩余 8.53322416 元，无未结算请求。

三位 `gpt-6.1-sol`（medium）子代理分别盲评 14、13、13 点。40 份评分均已导入并核验来源、评审配置与逐字引用，无待复核或未交付点。盲评没有额外 API 支出。

| 40 点同样本指标 | v8 | v9（v0.16.14） |
| --- | ---: | ---: |
| 质量通过 | 38/40（95%） | 35/40（87.5%） |
| 内容均分（满分 4） | 3.675 | 3.560 |
| 含重大错误的答案 | 2 | 5 |
| 问题记录（重大 / 轻微） | 2 / 25 | 5 / 24 |

两条旧重大错误均未复现：打 6 筒后正确说明只听 3 筒、4 筒；弃 5 万后正确说明补 2 万可成三色同顺。两点的共同五维均分均为 4/4。原来通过的 38 点中，33 点继续通过，5 点出现新的重大错误：

| 样本 | 新重大错误 |
| --- | --- |
| `d-7dd402bad11e14bbc8bf193f` | 弃 8 万后听 6 索、8 索，两对形成双碰，回答却误称嵌张。 |
| `expanded-east1-h0-p86` | 弃西后仍一向听，5 万、8 万是推进到听牌的进张，回答误称已经听牌。 |
| `expanded-east1-h0-p2` | 弃掉暗手唯一一张西后，回答仍把西列入弃后孤张集合。 |
| `expanded-south2-h2-p72` | 把赤 5 万说成普通牌，并否认它的赤宝牌价值。 |
| `d-06fc9e61eec0210e70e0ebbe` | 对家立直前亲自打过东，答案误称东是其立直后通过的牌。现物结论成立，依据和时点有误。 |

v9 修复了两个目标错例，但未满足「无新增重大错误」的验收条件。在这批定向样本上，v8 仍是表现更好的对照基准。下一轮宜优先约束模型区分一向听进张和零向听听口，听型未经确认时省略，并分别核对弃前弃后集合、赤宝牌身份和对手现物依据。样本为定向选取，不用于推断总体通过率。

本轮证据目录 `research/evidence/current-teaching-v9-targeted-cny10-20261119/` 中的 `BLIND_REVIEW_SUMMARY.json` 保存汇总与评审证明，`PAIRED_BLIND_RESULTS.json` 保存逐点成绩和错误引用，`import-targeted-review.local.cjs` 可复查导入结果。
