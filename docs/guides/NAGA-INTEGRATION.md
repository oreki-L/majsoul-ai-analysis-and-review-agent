# NAGA 可选牌谱导出

首版已实现本地转换、选局预览、复制／下载和官方提交页入口，默认关闭，仅完整版提供。没有接入账号、自动上传、扣费、任务轮询或报告回读；转换成功不表示 NAGA 已受理。LLM 仍是主要分析功能，Mortal/mjai 保持独立可选，均不依赖 NAGA。

## 使用流程

1. 在游戏中打开完整牌谱，待获取器载入完整记录；实时局面、历史结算快照和当前游标快照不能替代完整牌谱。
2. 展开“牌谱复盘 · NAGA”，启用本页导出，明确选择东风／半庄、各色一枚赤牌／无赤牌、四人喰断开启，并确认这些规则与牌谱一致。规则不从不完整元数据猜测。
3. 生成全场牌谱文本。转换始终读取整份 `replayRecords`，不截断于当前游标；成功局与拒绝局分别显示。选择要导出的局，核对预览后复制或下载文本。
4. 打开 [NAGA 官方提交页](https://naga.dmv.nico/naga_report/order_form/)，自行登录、粘贴逐局 URL、核对模型、额度和官方费用，再决定提交。扩展不收集密码、cookies 或其他会话凭据。

每行是一个 `https://tenhou.net/5/#json=...` URL，仅含一小局的天凤牌谱编辑器 JSON。导出包含牌谱四家初始牌与摸打、鸣牌、宝牌及结算；玩家昵称替换为座位标签，不保留账号、未来牌山或原始网络报文。用户自行复制和提交这些四家手牌数据。

## 首版支持范围

| 项目 | 边界 |
| --- | --- |
| 输入 | `mj-observer-v1` 的完整 replay；记录从 `recordIndex=0` 连续，来源均为 replay，以开局开始，每局有结算，不接受历史视图 |
| 规则 | 用户确认的标准四麻、东风或半庄、喰断开启；各色一枚赤五或全无赤牌 |
| 配牌 | 四家各13张；庄家14张时仅接受首弃摸切、能据此确认首摸的记录，不猜测数组末张 |
| 动作 | 摸打、吃、碰、明杠、暗杠、加杠、立直及宝牌变化；同时校验顺序、持牌和数量 |
| 结算 | 单家和牌、普通荒牌流局；要求可确认的役种、番符、支付点数及需要的里宝牌资料 |
| 役种 | 静态中日役名白名单；未知名称不按未核实的数字 ID 猜测，也不原样输出 |
| 拒绝 | 三麻、多家和牌、包牌、流局满贯、途中流局、拔北、未知事件、缺帧、缺结算、规则／牌操作矛盾与缺必要字段 |

不支持的小局单列原因，其余有效局仍可选择导出。“完整”是记录及结构校验通过，不代表已证明所有客户端版本或线上牌谱兼容。现有历史结算导出也不能用于补造缺失摸打。

若客户端牌谱只含役种数字 ID 而没有已知役名，该局会拒绝；当前没有经过核实的 ID 对照表。支付点数是否包含本场，以四家精确结算交叉验证，不能唯一解释时拒绝；含义不明的包牌标志也保守拒绝。真实牌谱可转换覆盖率仍待核对。

## 组件与数据隔离

- `extension/adapters/naga-replay.js` 为独立纯转换器；`MJNagaReplay.fromObservation(observation, { rules })` 返回 `majsoul-naga-export-v1`、成功局、拒绝局及逐行 URL 文本，不含 DOM、网络、账户或扣费逻辑。
- `extension/naga-panel.js` / `.css` 只处理规则确认、选局、只读预览、复制／下载及固定官方链接。组合入口注入完整牌谱导出端口，不将 NAGA 作为实时 `analyzeSnapshot` 后端。
- `protocol.js` 仅对 replay 增加选定的役种、里宝牌、支付点数与结算信息；未扩展 live 输出。缺失支付点数保留 `null`，未知结算有显式标志。
- `mj-analysis-v1` 与 LLM 发送范围不变，NAGA 结算细节不会顺带进入模型合同。Collector 构建不含转换器或 NAGA UI；无新增服务权限。

实现参考公开的[天凤格式说明](https://tenhou.net/mjlog.html)、协议字段说明及 [honvl/Majsoul-to-NAGA](https://github.com/honvl/Majsoul-to-NAGA)、[AsaChiri/majsoul-naga](https://github.com/AsaChiri/majsoul-naga)的流程与输出边界，代码独立实现。没有移植其转换／提交实现、真实用户牌谱或账号素材，没有把参考项目作为运行依赖。

## 官方服务与报告边界

截至2026-10-23，[官方说明](https://naga.dmv.nico/naga_report/)提供天凤牌谱编辑器格式的自定义分析，使用用户自己的账号、会员／NP 和额度；未确认面向本项目的稳定公开第三方 API。官方价格、可用模型及提交结果应由用户在官网核对，本项目不报价或声称已完成官方接入。

官方说明中的“解析レポートは、本サービスおよび天鳳と競合する製品の開発・応用を目的として利用することはできません。”限制与开源转换代码许可分别适用。本版不抓取、内嵌、再处理报告，也不将报告送往 LLM。报告回读若将来需要，必须另行确认接口与许可范围。

## 验证状态

人工协议帧回归已验证 replay 字段白名单、live 形状保持、特殊结算标志及模型合同隔离。转换、面板、完整构建和全仓测试的本轮最终结果见 [VALIDATION.md](../../VALIDATION.md)。尚无用户真实账号提交、NAGA 官方受理或报告结果验证；本地测试不能替代这些证据。
