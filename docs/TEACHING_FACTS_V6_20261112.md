## 本轮变更

保留此前程序提供的中文局名、自风、本场、各家巡目、精确弃牌对应效率，以及“牌／已见／未见上界”和“弃牌／向听／未见进张上界”两个三列表。是否比较备选继续由模型自行判断。

| 方向 | 程序新增事实 | 解释约束 |
| --- | --- | --- |
| 动作前后状态 | `actionTransition` 提供弃牌、摸牌、手切／摸切、弃前弃后自家同种枚数、向听及变化、孤张集合 | 起点是当前冻结暗手，已包含已知摸牌，也可能已经完成鸣牌；不能当成摸牌前。向听不变须称维持，不能说推进 |
| 已有组合明暗 | 自家和各家已有组合标注“明顺子／明刻／明杠／暗杠”，保留实体牌 | 不能把明刻或暗杠称为暗刻。类型、牌数或牌形不一致时标为不可用 |
| 牌形与孤张 | 列出全部孤张，给同种组与搭子附上“对子形／刻子形／四张同种（未宣杠）”及“边张／嵌张／两面”名称 | 只有相应孤张集合确实仅一张，才能说唯一孤张；局部组合可重叠，不能相加成整手拆分 |
| 解释依据不足 | 提示词允许在 `limitations` 说明现有依据不足以确定引擎取舍 | `reasons` 仅保留可核实事实，不用“唯一浮牌”“宝牌是负担”“单张役牌无法成刻”等断言补造动机 |

`isolatedTiles` 的精确定义是：当前暗手中没有同种伙伴，数牌也没有同花色相邻或隔一张联系的单张。赤五与普通五合并检查关系后保留实体身份。该定义不判断安全性、打点或未来价值；未知牌、非法牌及同种超过四张时不输出完整孤张断言。

`actionTransition` 仅处理已确认的弃牌，包括已有明确配套弃牌的立直。没有配套弃牌、弃牌实体不在暗手中、鸣牌或其他动作时不猜后续手牌；未知向听、手切／摸切保持未知。此处复用现有本地向听计算，不引入另一套牌理算法。

回答 JSON 仍为 `summary / reasons / limitations`，教学文本仍不能变更引擎动作。新增事实通过生产 Worker/Pi 链路传入模型；当前动作索引使用字段路径指向新事实，避免额外复制一套新表。

## 验证

- 63 项定向测试通过，覆盖新事实、提示词及生产 Worker/Pi 的工具续接、格式修正和失败保留 Mortal 动作。
- 127 个历史冻结局面完成离线核验：127 次动作状态核对、254 次弃前／弃后向听重算、254 套孤张集合核对，并检查各家组合标签、三列表与快照不变性。
- 向听核验使用同一个 `Analysis.shanten` 重新计算；这验证数据投影的一致性，不是第二套独立牌理算法。孤张集合另用实体伙伴枚数的方式核对。
- `npm run check`、`npm run build`、`npm run eval` 已通过。`eval` 的 3 项为合成本地向听回归，不衡量模型质量或实战强度。
- 全量 `npm test` 共 872 项：869 通过、0 失败、3 跳过（约 448 秒）。详细结果与源码哈希见下方 `VERIFICATION.json`。
