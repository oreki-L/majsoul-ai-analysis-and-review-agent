## 依据与优化目标

上一轮同一批 127 个局面中，发布版 A 通过 71/127，三列表 B 通过 83/127；但 B 有 3 次未交付，失败计零后的均分仅从 3.219 提高到 3.246。两组牌形／数量范围类错误均为 34 条；安全性错误为 A 21 条、B 22 条。程序计数本身不足以保证正确解释。

优先解决：把未见 0 误解为已有形状无价值；把单张误作孤张、忽略可共用实体牌的局部联系；摘要与正文事实矛盾；错误复用旧教学；JSON 缺数组或多出禁止字段。备选比较继续由模型按教学需要自行决定。

## 候选

| 候选 | 基础与变动 | 要检验的假设 | 主要代价或风险 |
|---|---|---|---|
| S1 `s1-semantics` | 上轮 B 加短规则：数量含义、可选牌形、摘要一致性、精确 JSON 键和类型 | 模型已经拿到事实，补足如何读取和解释，能否减少错误 | 增加提示词；仍是软约束，不能保证 JSON 或事实正确 |
| S2 `s2-action-focus` | S1 加程序生成的 `explanationFocus` 当前动作索引 | 把关键事实集中到当前动作，能否减少跨字段误读 | 完整 facts 保留，因此输入会增加，不能声称是压缩方案 |
| S3 `s3-history-isolation` | S2 在自动分析时去掉旧教学正文，保留历史动作、时点及已采集事件 | 错误是否经旧教学重复传播，清除后是否改善 | 可能影响教学承接；显式用户追问不隔离 |

三套为递进设计，S2 对比 S1 观察聚焦索引的增量，S3 对比 S2 观察历史处理的增量。S1 是一组共同的规则改进，不能单独归因到其中某一句提示。B 的上轮结果仅作历史参照，默认不再付费重跑 B，也不新增纯 LLM 组。代码中的 `b-compact-control` 用于离线检查与上轮投影一致。

### S1：补规则，不让模型自己重新数牌

- 未见上界 0 表示没有未见的同种牌，不否定手里已经拥有的对子／刻子，不否定其他牌能完成的搭子，也不影响已有现物证据。
- 数据完整且已见四枚时，可以说同种牌已全见；不能套用“任何上界都无法判断”的通用免责声明。数据不完整或冲突时不作见尽断言。
- “单张”只说同种数量，“孤张”还要检查相邻和间隔联系。3筒可参与123顺子，也可作为35筒嵌张的材料；可选联系可以重叠，不能把这些组合相加成唯一拆分。
- 形状向听为程序计算值，只有未见进张枚数是上界。各候选必须用自己的对应数值，不因同向听就声称进张相同。
- summary 也要核对事实，不能正文承认三张8索，摘要却说“没有任何面子”。
- JSON 只含 `summary`、`reasons`、`limitations`，后两项是字符串数组，可写 `[]`；不改生产解析器和一次格式修正机制，禁止字段仍按原合同处理。

### S2：只增加当前动作的读取索引

逐牌计数表继续只有「牌／已见／未见上界」三列，不增加列数。

额外索引由程序从当前冻结 snapshot 及正式 facts 生成，包含：场风与自风、庄家座位、弃前后暗手总数、当前弃牌同种持有数、弃前后与该牌有关的局部搭子、可组成的同种组与顺子、当前弃牌的效率计算，以及该牌对指定对手的本人牌河现物证据。无须推断的部分直接引用，未知值保留 `null`。

索引不是完整整手拆分，也不是 Mortal 内部动机。现物部分只汇总已有本人牌河的正向证据，未列座位不等于不安全。本轮实现没有新增“立直后他家打出并通过”的时序计算，该证据仍需查完整事件；不能把它宣传为安全性算法已修复。

### S3：隔离自动分析的旧教学

只对 `question === ""` 的自动分析处理。历史建议保留动作、decisionId、position 和 task；旧 summary、reasons、limitations 和 explanation 正文移除。历史事件、授权旧快照和当前事实保留，不从动作反推旧理由。显式用户追问保持原上下文。

这样能直接检验重复出现的“无面子”“孤张”“早期牌河”等措辞，是否部分来自旧教学。它并不代表已经证明历史文本是错误原因。
