# 实时分析：当前事实、效率与风险

v0.12.0 的自动实时 Chat 分析使用 `live-ned`。核心是先把当前事实与本地计算交给模型，再让模型解释取舍；用户继续使用自己的 API，无需专业麻将引擎。

## 每次模型看到什么

| 内容 | 具体范围 |
| --- | --- |
| 当前完整授权局面 | 用户授权的桌面、自家手牌、全部已授权且有序的牌河；缺失和未授权字段不补齐 |
| 语义导航 N | 数据来源与事件位置、自家座位和人数、局与本场、庄家与座风、分数、暗手牌计数、赤五／普通五、新摸牌与宝牌含义 |
| 本地效率 E | 与 `compare_discards` 相同算法和冻结输入的状态、候选、向听及有效牌；未见枚数只是上界，不是牌山精确枚数 |
| 逐家风险 D | 与 `get_danger_evidence` 相同的现物、筋、壁，附对应牌河来源；当前公开立直、副露见局面与导航 |
| 重要事件 | 当前时点之前已授权且已采集的开局标识、立直宣言、吃碰杠、拔北和终局；不补造缺失变化 |
| 任务与合法约束 | 当前任务、合法弃牌、风险候选和对手座位，最终仍由本地严格校验 |

综合攻守主动提供 N/E/D；牌效率仅 N/E；危险牌分析仅 N/D，保持不能给具体弃牌决策的任务边界。多候选的综合或效率请求要求比较至少一个实质备选；不能保证任意模型都会遵从或解释正确。无可靠计算时保留不可用状态及原因，不让模型猜数值。

手牌已经包含已知的新摸牌，不能再次追加。原始赤五与普通五不同，形状计数才合并；三麻万子宝牌按 `1m→9m→1m` 循环，未知或不合法指示牌不强套四麻。`round.index` 是庄家座位，不是整盘局序。筋、壁不保证安全；缺少证据不等于安全或确定危险，不能据此编造放铳概率。

## 哪些历史不重发

自动实时默认不发送旧完整快照、开局完整基线、旧自动建议及其他决策分支问答。当前完整牌河仍是主动信息，普通动作的详细时序可用只读工具查询。

本地仍保存有界的完整授权基线、增量、请求和答案，小局会话身份继续保留。请求投影不是删除记录：回看与冻结决策追问仍使用当时局面和本分支问答，不混入后续巡目；手动全局、牌谱普通分析维持原合同。用户记忆继续按既有固定版本工具读取，本版不新增后台 LLM 上下文摘要、跨局画像任务或通用双调用复核。

六个只读工具仍可用；已经附上且绑定同一冻结状态的计算可直接使用，缺项或有疑义再查询。动态局面和候选放在 user 数据中，同任务系统规则保持稳定；稳定前缀不保证服务商缓存命中。

## 完成结果与请求预算

新巡请求开始、失败、超时或取消，都保留上一份完成的实时建议。它会标明旧时点，过时牌面不作为当前出牌提示；晚到结果不能覆盖新时点，用户仍能回到旧决策追问。

产品维持自动实时最多 **2 次模型请求、4 次工具调用、25 秒**，思考模式超时 **120 秒**。手动全局／复盘最多3次模型请求。最终回答也计入请求预算，不无限重试；失败和取消可能已产生服务商用量。实验中无额外调用截断的条件与产品不同，不能直接搬用实验耗时或质量数字。

本次发布使用人工局面和模拟响应验证请求合同、规则与展示，没有调用真实收费模型，也未得出新版质量、牌力或费用改善结论。上下文组织有助于模型读取证据，实际输出质量仍取决于模型、局面、服务能力及预算。用量、缓存与未知费用的处理见 [AGENT_SESSIONS.md](AGENT_SESSIONS.md)。
