# Mortal 教学 S2 生产接入验证（v0.16.9）

本版将 S2 当前动作事实索引接入生产，并补充程序可核实的安全证据和局部搭子完成牌。新版尚未运行真实 LLM 调用或独立质量评分；旧实验成绩只能说明选择 S2 的依据。发布资产、远端 CI 和匿名下载结果以本版 Release 回执为准。

## 选择依据与实现

上一轮在同一批 127 个局面分别评测 S1、S2、S3，共 381 份答案，全部交付并完成独立盲评。S1 通过 87/127（68.50%），均分 3.209/4；S2 通过 107/127（84.25%），均分 3.550/4；S3 通过 99/127（77.95%），均分 3.387/4。重大错误答案分别为 40、20、28 份。S2 保留既有历史教学承接，S3 的自动历史隔离未采用。

S2 仍有牌形、效率、安全性和座位／时点误述，不能将采用 S2 等同于这些问题已经消失。本版针对可确定的事实补齐输入：

- 计数表固定为「牌／已见／未见上界」三列，赤五与普通五合并同种四枚上限，并保留动作实体身份。已见包括自家暗手与公开牌；弃牌只改变所在区域。未见上界不是牌山剩余。
- 当前动作索引集中提供风位、各家立直／副露情况、弃前后手数、同种持有数、局部组形及当前弃牌自身的效率对象，不拿最佳候选数值解释另一个动作。
- 局部搭子直接列真正需要的完成牌及其未见上界，例如 89 看 7、12 看 3、35 看 4；这些局部联系可以共用实体牌，不代表唯一整手拆分。
- 对每个对手给出具名安全证据：本人牌河、立直后他家打出并通过、四麻完整可见计数排除等待。风险工具与事实卡返回同一份证据。
- 解释提示升级到 v4，要求摘要与理由核对事实、按对应动作引用数值，允许证据不足时说明局限。备选比较仍由模型按教学需要决定，保留 `summary / reasons / limitations` 合同及既有一次格式修正。

## 安全证据边界

`confirmed` 仅表示充分证据支持指定对手在当前冻结时点不能荣和该牌；`unknown` 表示未能证明，不等于不安全，不推断其他牌或未来。

立直后通过证据要求同来源、截至冻结时点、同一局内的授权事件；snapshot 中该对手已立直且存在对应立直弃牌。之后他家弃牌须已被更晚的有效游戏动作确认通过，当前尚待响应的弃牌不构成证据。终局、未来事件、来源不符或冲突输入均不能证明通过。同家事件弃牌须能按顺序匹配当前牌河，缺失观察允许有序子序列，顺序冲突则拒绝时序证据；相同位置的重复观察先去重。

可见排除仅用于四麻完整且无冲突的计数：该牌四枚已见还不足以确定安全，须逐一排除所有包含该牌的顺子等待；幺九字牌还须以另一种已全见的幺九字牌排除国士等待。三麻、partial、invalid 或计数不可用时不使用这条证明。它不是完整危险度算法或对手手牌推断。
