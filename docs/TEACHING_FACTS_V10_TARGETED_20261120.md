# Mortal 教学 v10 定向实测

提示词 v10、事实卡 v9 的 14 点真实回放全部交付。用同一规则重新盲评后，内容均分比 v8 高 0.200/4，通过数和重大错误数持平。两条原错误得到修复，但有两条原本通过的答卷出现新错误，因此本轮结果不足以替换 v8 作为质量基准。

## 改动与样本

- 程序明确区分未听牌的进张和形状听牌的听口；只在可验证的情况下标记双碰。保留所选弃牌的整手听口和三色同顺、役牌的正面证据。
- 所选牌种是否为孤张分弃牌前后给出；赤五身份与指示牌宝牌分开；安全依据按对手列出，分别说明本人曾弃、立直后通过和公开牌排除等待。模型可以自行决定是否比较备选。
- 14 点包含 [v9 实测](TEACHING_FACTS_V9_TARGETED_20261119.md) 的 5 个退步点、2 个已修复点和 7 个代表点。v10 沿用相同快照、缓存 Mortal 动作和历史输入；仅调用真实 API 生成 v10，复用 v8 的原始答卷。未重新运行 Mortal。
- 28 份答卷以随机 ID 混排，同点的两份答卷由同一评审分别评分。三位评审均为 `gpt-6.2-sol`（`low`）。所有答卷的来源、规则哈希、评审配置及逐字引文已检验。v8 的分数来自这次重新评分；此前的 40 点及 `gpt-6.1-sol` 评分不纳入本表。

执行 `npm run check` 和完整 `npm test`：873 项通过、3 项跳过、0 项失败。离线回放覆盖 14/14，包含直接回答、工具续接和格式修复，无 API 调用。

研究工作区的冻结证据位于 `research/evidence/current-teaching-v10-targeted-cny10-20261120-r2/`。`PAIRED_BLIND_RESULTS.json` 保存逐点评分和错误引文，`BLIND_REVIEW_SUMMARY.json` 保存汇总、费用和评审证明。实验入口是 `benchmark/current-teaching-v10/regression.cjs`，支持 `prepare`、`verify`、`--dispatch` 和 `export-paired`；`import-paired-review.local.cjs` 可验证已归档的评审结果且不发出请求。
