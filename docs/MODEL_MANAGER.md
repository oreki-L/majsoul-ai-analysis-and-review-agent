# 本机模型管理

模型目录、已安装权重与运行中的分析服务分别管理。可以保持零模型；安装扩展、打开设置或启动管理终端，都不会下载权重或启动推理。普通 LLM 功能无需 Mortal、Akagi 或 Python。

## 打开管理页

安装 Node.js 22.19 或更高版本，将 `majsoul-model-manager-windows-x64-0.14.0.zip` 完整解压到可写目录，运行其中的 `start.cmd`。它先校验分发文件，再启动本机管理页；安装数据保存在包内 `installations/`。不需要预装 Python 或 Rust，保持终端运行才能继续管理。包内 `README.md` 提供简洁操作步骤。

打开终端显示的管理地址（默认 `http://127.0.0.1:17343/`），将终端的**管理 Token** 粘贴到页面后点击“连接”。扩展设置的“本地 mjai”区域也提供默认端口的网页入口。入口只打开网页，不会启动本机程序；端口有变化时，以终端地址为准。

默认包包含经校验的 native 组件、管理脚本、对应源码和许可，不含权重或完整 Python。选择安装后，管理器才按固定来源准备 Python、wheels 和该模型权重。首次安装需要网络；已实际从官方源下载 Python 和全部10个固定 wheel，完成便携环境原子安装与全文件哈希校验。本机连接 HF 权重源失败，因此完整在线模型安装尚未通过；完整模型离线安装已实测。下载受本机网络环境影响，网络或校验失败会显示错误，不会改用其他模型或 LLM。另行明确导出的离线工具包可含归档与 wheels，仍不要求预装全部模型。

管理 Token 只保留在当前页面内存，不放入 URL、不写入浏览器存储；刷新或断开后需要重新输入。它只能管理安装与启停，不能当成扩展的分析 Bearer Token。

## 安装、使用与切换

1. 在模型目录检查来源、权重大小、适用范围、许可及验证边界。目录中出现的模型不代表已经安装；未验证候选不可安装或运行。
2. 点击所需模型的“安装”。管理器只准备该模型权重与必要环境；VoidShine 无需先下载 Akagi。页面显示服务回报的操作状态；没有字节进度时显示不确定进度，不估算完成百分比。
3. 安装完成后点击“启动分析”。安装本身不会启动推理。一次只运行一个模型；对另一已安装模型点击“切换并启动”时，其他模型的已安装资产仍保留。
4. 将“当前分析服务”区域的分析接口、**分析 Bearer Token** 复制到扩展中对应的本地引擎配置。手动开启模型分析、保存并授予接口权限。管理 Token 和分析 Token 必须分开使用。
5. 用完点击“停止分析服务”。扩展关闭分析只停止发出请求；要释放模型进程，请在管理页停止服务或退出管理终端。

切换扩展中的本地引擎配置会关闭分析，并保留各配置自己的地址与分析 Token。旧配置保持为“原本地引擎（身份未确认）”，不按端口猜测其模型；也可继续使用自定义 mjai 服务。仅切换目录或配置，不会下载、删除资产或启用分析。

## 模型与资产边界

| 候选 | 当前范围 |
| --- | --- |
| Akagi v2 弱 Mortal 示例 | 固定旧版示例，用于回归；不等于官网 Mortal 4.1 |
| VoidShine/mortal-298k | 社区 Mortal v4 四麻半庄模型；作者不推荐排位；限定验证不等于整场兼容或牌力认证 |
| Yuchen1457/mortal-582500 | 社区 Mortal v4 模型；严格权重加载、四座位、100 个 HTTP→Agent 决策点和 19 个关键／官方对照夹具通过；保守限制四人半庄且逐次手动声明，不代表本地牌力认证 |

通过工具包 `start.cmd` 启动时，安装目录为包内 `installations/`。开发者直接运行 `node agent/model-manager.cjs --toolkit LOCAL_TOOLKIT_DIR --root MANAGED_DIR --port 17343` 时，需将两个目录占位符替换为实际路径；页面显示服务实际使用的目录。

页面读取管理器报告的真实安装目录与环境状态，不扫描任意用户文件夹。环境是否共享由目录元信息明确显示；未确认共享时不会宣称共享。删除仅处理 `root/models/{id}` 中由管理器拥有且通过文件哈希校验的该模型资产，不删除 `root/runtimes` 环境，也不接管外部自备目录。运行中的模型需先停止才能删除。删除权重后，再次使用需要重新安装。

此管理器不设置开机自启、系统服务、计划任务或 Chrome Native Messaging。管理服务只绑定本机地址；保持终端运行才能继续管理。未连接管理 Token 时，页面不发送目录或操作请求。

## 错误与验证范围

按钮点击后先显示“已受理／等待状态更新”；只有管理器确认完成才显示完成。下载失败、校验不符、启动失败或协议不匹配会显示错误，不能把安装目录存在当成可用，也不会静默切到其他模型。

37 项 UI／设置测试覆盖空目录、未验证模型禁用、显式连接、管理／分析 Token 隔离、停止后清空分析凭据、失败不伪造安装成功，以及现有扩展配置迁移和独立 Token。真实浏览器已使用离线工具包完成两个 v4 模型安装、启动、切换、停止和删除，并检查窄屏；详细 QA 和运行日志保留于本机证据，不随发布包分发。模型 HTTP 动作合同与验证边界见 [验收记录](MORTAL_V4_VALIDATION.md)。
