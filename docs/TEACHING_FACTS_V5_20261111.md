# 当前教学事实输入优化（2026-11-11）

基于 v0.16.9 单独实测暴露的局次、巡目和候选数值误用，当前工作区已实现以下调整。尚未发布；现已完成新提示词的真实LLM实测与独立质量评分。

- 解释提示版本从4升至5，事实卡从v3升至v4；JSON回答合同不变。
- currentContext直接给出中文roundName、自风selfWind、本场honba、自家selfTurn和逐家巡目。只认可events来源且完整合法的turnProgress；未知值保持null，不以事件位置、本场数或历史教学补齐。
- candidateEfficiency使用三列“弃牌／向听／未见进张上界”，按精确编码逐行绑定，赤五单列；不将效率排序当成引擎偏好或合法动作证明。动作索引引用此表，避免再复制一份完整表。
- 保留已有手牌可见计数三列表。是否比较备选仍由模型根据教学价值决定；没有新增强制比较要求。
- 自动教学历史新增historical-model-advice、currentFacts:false、actionWasExecuted:null，保留此前教学正文，但明确其可能有错、不能作为当前事实或已执行记录。提示词要求冲突时优先当前快照和事实卡。
- benchmark/mortal-teaching/released-v0169保存从已发布commit提取的三份原始源码；历史v0.16.9运行时测试固定读取这些源码，避免把当前v5输入冒充旧发布输入。
