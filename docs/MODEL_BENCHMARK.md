# DeepSeek 接入与小样本实测

可以先试 **DeepSeek-V4.1-Flash**：本项目已有官方 API 的小样本记录，价格与速度适合起步体验。这里没有跨模型对照，不能据此认定它是最佳模型，也不声称达到 MAKA、Mortal 的牌力。本文仅公开可复算的聚合数据，不包含原牌谱、截图、账号信息或 API 凭据。

## 接入

| 设置项 | 值 |
| --- | --- |
| 模型 ID | `deepseek-flash` |
| 完整接口 | `https://api.deepseek.com/chat/completions` |
| API Key | 用户自行申请并填写 |
| 所述实验的思考模式 | 关闭 |
| 所述实验每次 HTTP 输出上限 | 2048 tokens |

设置支持填写完整接口，也支持仅填 `https://api.deepseek.com` 后自动补全 `/chat/completions`。不需要模型之外的专业引擎。官方 API 默认开启思考，本扩展可显式关闭；默认输出上限与实验设置可能不同。

2026-10-26 核查[官方首次调用说明](https://api-docs.deepseek.com/)与[价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，`deepseek-flash` 对应 **DeepSeek-V4.1-Flash-1017**，支持 tools 与 JSON 输出。2026-10-25 实验时的官方价格审查也记录了此映射。实测记录使用这个 API 别名，不代表锁定了不可变模型快照。

## 官方人民币报价

以下为 **2026-10-26 核查值，每百万 tokens**，不是价格生效日期。中文官方报价直接以人民币列示，不使用美元换算。

| 项目 | 高峰 | 空闲 |
| --- | ---: | ---: |
| 输入，缓存未命中 | ¥2 | ¥1 |
| 输入，缓存命中 | ¥0.04 | ¥0.02 |
| 输出 | ¥8 | ¥4 |

高峰为北京时间周一至周五 **09:00–12:00、14:00–18:00**，中国法定节假日除外；其余时间包括周末与法定节假日为空闲。第三方网关价格可能不同，价格和别名映射均可能调整，以[官方当前价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)及实际账户结算为准。

## 39 点 B 方案结果

数据来自 2026-10-25 小样本研究的 R1 协议。B 方案发送完整当前授权快照、已采集完整小局事件和本组成功问答。共同设置为单一 `deepseek-flash`、`temperature=0`、`thinking.type=disabled`，每次分析最多 **2 次 HTTP／4 次本地工具调用**，每次 HTTP `max_tokens=2048`。没有启用付费服务端搜索或抓取。R1 使用研究提示后缀，不等同于当前扩展默认提示和运行流程；没有为本文重新调用付费 API。

| 指标 | 全部 R1 B：39 点 | 其中初筛：12 点 | 其中扩样：27 点 |
| --- | ---: | ---: | ---: |
| 结构有效输出 | 38/39（97.4%） | 11/12（91.7%） | 27/27（100%） |
| MAKA 首选一致 | 16/39（41.0%） | 6/12（50.0%） | 10/27（37.0%） |
| 失败 | 1 | 1 | 0 |

一致率分母包含所有计划决策，失败计不一致；没有只用有效输出提高比例，也没有把初筛的50%代替总体41%。初筛与扩样合计39点，来自同一场牌谱，不能视为39场独立对局。MAKA 标签仍为临时标签，未完成全量人工语义核验；一致仅表示推荐相同，不是建议正确率、胜率或牌力。

38 个结构有效结果中，**16 个 `decision.reasons` 为空**。结构有效只表示通过输出合同校验，不表示解释完整、事实无误或策略正确；本文没有完整的解释质量评分。

| 时间与费用指标 | 全部39点 |
| --- | ---: |
| HTTP 请求数 | 52 |
| 每分析 HTTP 累计耗时中位数 | 5.63 秒 |
| 每分析 HTTP 累计耗时均值 | 6.00 秒 |
| 每分析 HTTP 累计耗时 P95 | 8.47 秒 |
| 按高峰价与实际缓存用量估算，总计 | ¥0.91981944 |
| 同口径平均每分析 | ¥0.023585…，约 ¥0.024 |

耗时为同一分析内各 HTTP 请求的计时之和，不是从牌局变化到界面显示的端到端时间，也不是单请求首 token 延迟。网络、文本长度、工具调用、缓存与服务负载会影响结果。P95 使用 nearest-rank 统计。

费用根据返回的 token usage 与上述高峰单价估计，**未查询账户账单，不是实付金额**。不保证每次、每局或每百次都具有相同费用；这里也不包含追问、后续模型设置变更和可选整场记忆总结。
