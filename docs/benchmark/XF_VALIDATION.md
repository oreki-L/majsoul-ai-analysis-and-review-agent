## 不能从本批推出什么

- 45个节点来自同一牌谱且相关，不证明跨牌谱稳定收益或统计上的独立样本优势；X-F只在本批观察领先，分局并非处处最好。
- 实验允许180秒逻辑总deadline、结构修复与恢复；产品实时最多2次模型请求、25秒（思考120秒）。本表不是发布版线上质量保证。
- C-KM使用自身新局成功历史，消费/回退为事后状态，不能解释成纯摘要单因素随机实验。摘要语义10/10通过也不能替代主答质量。
- 供应商缓存、Key和执行顺序存在混杂。X-F已知usage估费0.58884924元，同时还有2.12992元未知timeout保守hold；hold不是实付、未知不按零。因此不据此宣传更便宜或更快，也不与旧39点费用或旧NED29点跨轮比较。
- 产品移植只做离线原payload等价、人工局面/模拟模型回归与构建，没有新真实模型/游戏测试。45/45构造等价不证明真实产品用户历史、时延、收费或质量相同。

## 移植来源与离线核对

`extension/xf-context.js`保留冻结实现中的导航、N/E/D投影、重要事件/状态差分、旧事实intern以及原版 `phase3-compact-facts/1` 目录；来源校验值见 [xf-provenance.json](../xf-provenance.json)。原 `Next.build(X-S)` 加 `Facts.attach(claims:false)` 是依据；不拼接其他候选，不改原实验规则或评分。

对原四个 X-F 冻结 run 的45个 initial 请求，以同一绑定node、原prepared与原来源重建后，system与各message原文/顺序逐条deepEqual通过。包括目录内容、stateId、source hash和catalog hash。原冻结实验里的一笔超时重发不另增逻辑机会。

本版新增回归验证：Node/浏览器SHA-256一致、全部历史超过8个检查点仍保留、历史/当前/未来分离、重要状态变化、旧意见排除、撤权拒绝、历史操作资格剥离、非适用任务NED回退与问答分支隔离。全仓检查/测试、双profile构建与3个人工向听样例另按 [发布验证记录](../../VALIDATION.md) 执行。
