第一次使用本地引擎

  1. 按接入指南准备指定版本的第三方 Bot，完成本机检查并启动桥接服务。
  2. 将终端显示的 /analyze 地址和 Bearer Token 填入下方；保持桥接终端运行。
  3. 手动开启分析、保存并授予本机接口权限；在牌局面板授权信息与自家手牌，确认座位后选择“综合攻守”并手动分析。

整场记忆学习

仅采集开启后 live 实战的已识别自家手牌、公开桌面和真实动作。请只在本人参与对局时开启；观看、牌谱和历史复盘不会自动学为自己。本机档案不跨账号识别，换账号前请关闭或清除。

小局结束只记录证据；明确整场东风 / 半庄结束，且至少 3 个覆盖可靠完整小局、20 个完整自家动作时，才使用当前自配模型额外请求一次总结。默认只新增待确认候选，额外 token 和费用单列在下方任务记录。实时分析优先；浏览器关闭或 worker 休眠不保证后台继续，未知请求不会自动重试。

关闭学习会取消待处理任务并停止采集和自动总结；已保存记忆仍可用于后续小局的解释重点，也可查看与删除。修正、删除或清除会取消旧会话，防止旧版本重新写回。
