安装与使用说明

先解压运行包并双击 start.cmd。连接时在管理页允许本扩展；连接只更新草稿，不开启分析。切换模型后请重新连接。

可以不安装任何模型。下载、删除和启停由本机管理页明确操作，切换保留已安装资产。运行包与扩展分别安装；启动管理页不会安装模型或运行推理。

两个社区 v4 模型共用已验证的运行库。限定人工局面验证不等于整场兼容、官网 4.1 或牌力认证。VoidShine 作者不推荐排位。

Magpie 与 CC Switch 说明

Magpie 适用于自主运行的网关，默认 http://127.0.0.1:3425/v1。Bearer 标识 magpie-majsoul-agent 不是上游 API Key，也不提供额度。模型 ID 原样发送，路由费用未知。

CC Switch 为可选实验接入，默认 http://127.0.0.1:15721/v1；须自行启用 Codex 路由并选支持 Chat Completions 的上游。调用共用 Codex 供应商、切换与用量统计，没有独立应用隔离。预设密钥留空，不读取桌面凭据；本机服务要求鉴权时请自行填写。Codex 目录可能为空，模型 ID 与 ccs- 前缀须原样保留。真实云模型及全面兼容仍未验证。

整场记忆学习

仅采集开启后的本人 live 实战；观看、牌谱和历史复盘不会自动学为自己。本机档案不跨账号识别，换账号前请关闭或清除。

整场结束且覆盖可靠的完整小局与动作达到门槛后，才使用当前自配模型额外请求总结。默认只新增待确认候选，可能产生额外费用。

学习与费用说明

明确整场东风或半庄结束，且至少有 3 个覆盖可靠的完整小局、20 个完整自家动作时，才请求一次总结。额外 token 和费用单列在任务记录。实时分析优先；浏览器关闭或 worker 休眠不保证后台继续，未知请求不会自动重试。

修正、删除或清除记忆会取消旧会话，防止旧版本重新写回。

关闭学习会停止采集和自动总结；已保存记忆仍可查看、删除并用于后续解释。
